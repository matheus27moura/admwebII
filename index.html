Como o PHP se encaixa no que você já sabe

HTML é a estrutura

Define o que aparece na página: títulos, textos, imagens, formulários. É o esqueleto.

CSS e JS ficam no navegador

CSS dá a aparência; JavaScript reage ao usuário. Os dois rodam no computador de quem visita o site.

PHP fica no servidor

Roda antes da página chegar ao navegador: monta o HTML, recebe formulários, guarda dados e conversa com outros sistemas.
